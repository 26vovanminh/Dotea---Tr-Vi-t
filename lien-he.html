Ví dụ hiện tại của bạn có: nav { display: flex; align-items: center; gap: 35px; background-color: #765237; padding: 18px 35px; border-radius: 6px; } Cách 1 — Menu ngắn lại theo đúng độ dài nội dung Thêm: nav { display: flex; align-items: center; gap: 35px; background-color: #765237; padding: 15px 30px; border-radius: 6px; width: fit-content; margin: 0 auto; } 👉 width: fit-content; là phần quan trọng nhất. Nó làm thanh menu chỉ rộng bằng phần nội dung bên trong, thay vì kéo dài cả màn hình. Nếu muốn thanh menu vẫn khá dài nhưng không full màn hình Dùng: nav { width: 70%; margin: 0 auto; } Ví dụ: ┌──────────────────────────────────────────┐ │ TRANG CHỦ GIỚI THIỆU SẢN PHẨM LIÊN HỆ │ └──────────────────────────────────────────┘ Còn width: fit-content sẽ kiểu: ┌────────────────────────────────┐ │ TRANG CHỦ GIỚI THIỆU SẢN PHẨM │ └────────────────────────────────┘ Với Dootea của bạn, mình nghiêng về width: fit-content vì nhìn gọn và giống một thanh menu riêng biệt hơn. ngắn lại ở bên phải À, ý bạn là giữ nguyên vị trí bên trái của thanh menu, chỉ muốn nó ngắn lại ở phía bên phải đúng không? Vậy không dùng width: fit-content và cũng không dùng margin: 0 auto. Chỉ cần giảm padding hoặc đặt chiều rộng cụ thể. Nếu CSS hiện tại là: nav { display: flex; align-items: center; gap: 35px; background-color: #765237; padding: 18px 35px; border-radius: 6px; } Bạn sửa thành: nav { display: flex; align-items: center; gap: 35px; background-color: #765237; padding: 18px 20px; border-radius: 6px; } Nếu vẫn còn dài bên phải, thì khả năng nav đang bị CSS khác ép width: 100%. Khi đó thêm: nav { width: calc(100% - 50px); } Thanh sẽ ngắn vào 50px ở tổng thể, nhưng nếu bạn muốn chỉ hụt 50px ở bên phải và bên trái giữ nguyên, dùng: nav { width: calc(100% - 50px); margin-right: 50px; } 👉 Nếu bạn gửi mình đoạn CSS nav hiện tại, mình có thể chỉ đúng 1 dòng cần sửa để nó ngắn đúng phía bên phải mà không làm lệch menu.
